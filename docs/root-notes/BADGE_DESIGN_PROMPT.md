# Prompt de Génération des Badges d'Habitudes

## Instructions pour l'IA de Génération d'Images

Génère **8 badges** (un par habitude). Chaque badge aura la **même icône** pour ses 4 évolutions, seule la **couleur du fond et de la bordure change** selon le niveau débloqué.

---

## Spécifications Techniques

- **Format** : PNG avec fond transparent
- **Dimensions** : 512×512px (haute résolution)
- **Style** : Flat design moderne, minimaliste, épuré
- **Forme** : Badge circulaire avec bordure métallique
- **Évolution** : Le badge garde la même icône, seule la couleur évolue (Bronze → Argent → Or → Diamant)

---

## Structure du Badge

```
┌─────────────────────┐
│   ╭───────────╮     │
│  ╱             ╲    │
│ │   [ICÔNE]     │   │ ← Icône blanche (identique pour les 4 niveaux)
│ │               │   │
│  ╲   Cercle    ╱    │ ← Fond coloré (change selon niveau)
│   ╰─────────────╯   │
│      Bordure        │ ← Bordure métallique (change selon niveau)
└─────────────────────┘
```

---

## 4 Niveaux d'Évolution (couleurs)

### 🥉 Bronze (25%)
- **Couleur fond** : #CD7F32 (bronze chaleureux)
- **Bordure** : Bronze métallique avec reflets cuivrés
- **Effet** : Mat, sobre, début de progression

### 🥈 Argent (50%)
- **Couleur fond** : #C0C0C0 (argent métallique)
- **Bordure** : Argent brillant avec reflets bleutés
- **Effet** : Brillant, reflets métalliques visibles

### 🥇 Or (75%)
- **Couleur fond** : #FFD700 (or éclatant)
- **Bordure** : Or brillant avec reflets jaunes intenses
- **Effet** : Très brillant, reflets dorés prononcés, léger glow

### 💎 Diamant (100%)
- **Couleur fond** : Dégradé arc-en-ciel subtil (#B9F2FF → #E0BBE4 → #FFDFD3)
- **Bordure** : Platine/diamant avec prismes et reflets multicolores
- **Effet** : Cristallin, facettes de diamant visibles, glow arc-en-ciel, éclat maximal

## 8 Badges à Générer (avec 4 versions chacun)

### Template Général

```
Create 4 evolution levels of the same circular achievement badge for a mobile app:

- **Habit**: [NOM_HABITUDE]
- **Icon**: [DESCRIPTION_ICONE] (same icon for all 4 levels, white color #FFFFFF)
- **4 Levels to generate**:

  **Level 1 - Bronze (25%)**:
  - Background: #CD7F32 (warm bronze)
  - Border: Bronze metallic with copper reflections
  - Effect: Matte, sober finish

  **Level 2 - Silver (50%)**:
  - Background: #C0C0C0 (metallic silver)
  - Border: Shiny silver with blue-tinted reflections
  - Effect: Shiny, visible metallic reflections

  **Level 3 - Gold (75%)**:
  - Background: #FFD700 (radiant gold)
  - Border: Brilliant gold with intense yellow reflections
  - Effect: Very shiny with golden glow

  **Level 4 - Diamond (100%)**:
  - Background: Rainbow gradient (#B9F2FF → #E0BBE4 → #FFDFD3)
  - Border: Platinum/diamond with prismatic facets and multicolor reflections
  - Effect: Crystalline with rainbow glow and maximum radiance

Style: Flat design, modern, minimalist, clean
Format: PNG 512×512px, transparent background
Design: The icon stays the SAME across all 4 levels, only the background color and border change
The badge should have a premium, polished look
```
