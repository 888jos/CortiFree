## 🎨 Style Artistique Global

### Directives Générales
- **Style**: Anime/Lo-fi minimaliste, inspiré du style japonais moderne
- **Ambiance**: Calme, apaisant, contemplatif
- **Technique**: Illustrations vectorielles simples avec dégradés doux
- **Couleurs**: Tons pastel et dégradés subtils qui s'intègrent à l'esthétique de l'app
- **Complexité**: Minimaliste - ne pas surcharger, privilégier la simplicité
- **Caractère**: Sans personnages humains détaillés, focus sur des éléments symboliques et abstraits

### Palette de Couleurs Principale
Utiliser des variations autour de ces gammes:
- **Bleus apaisants**: `#4FACFE`, `#00F2FE` (respiration, calme)
- **Violets méditatifs**: `#B794F6`, `#E0C3FC` (méditation, spiritualité)
- **Verts naturels**: `#43E97B`, `#38F9D7` (ancrage, nature)
- **Roses/Oranges énergisants**: `#FA709A`, `#FEE140` (énergie, positivité)
- **Violets profonds**: `#667EEA`, `#764BA2` (introspection)
- **Purples mystiques**: `#5F72BE`, `#9B23EA` (relaxation, sons)

### Éléments Visuels Récurrents
- Formes géométriques douces
- Dégradés subtils
- Particules lumineuses ou étoiles
- Textures légères (grain, bruit)
- Ombres portées douces
- Éclats de lumière (lens flare subtil)

## 🎯 Notes Techniques pour l'Intégration iOS

### Asset Catalog
Les images devront être ajoutées dans `Assets.xcassets` avec les variantes suivantes:
- **@1x**: Dimension de base
- **@2x**: Double résolution (pour iPhone standard)
- **@3x**: Triple résolution (pour iPhone Pro/Max)

### Exemples:
- `situation_submerge.png` → 600x600px (@1x), 1200x1200px (@2x), 1800x1800px (@3x)
- `exercise_guided_breathing.png` → 800x400px (@1x), 1600x800px (@2x), 2400x1200px (@3x)

### Nomenclature finale dans le code:
```swift
// Situations
Image("situation_submerge")
Image("situation_dormir")
Image("situation_tendu")
Image("situation_stresse")
Image("situation_anxiete")
Image("situation_energie")

// Exercices
Image("exercise_guided_breathing")
Image("exercise_grounding_5_senses")
// ... etc
```
